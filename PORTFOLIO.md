# CSV and JSON Export Preparation

Prepare small CSV exports for tools that need flat JSON, or convert flat JSON back to CSV. Explicit trimming, column renaming and first-occurrence deduplication preserve string values, Unicode and leading zeros. Existing destinations are never overwritten within the documented local-filesystem contract.

AI-assisted learning project using synthetic data. Includes reproducible examples, standard-library Python source, documented limits and 23 automated tests. No client engagement or commercial result is claimed. Supports flat string-valued tables only, UTF-8 and a 1 MiB limit; not nested JSON or arbitrary encoding conversion.
